# Insider Watch

## Rule-Based Insider Threat Detection System via User Behavior Monitoring

Insider Watch is a lightweight endpoint security prototype developed for Final Year Project. The system monitors selected user activities and generates explainable security alerts using predefined rule-based detection mechanisms.

## Features

- User session monitoring
- File activity monitoring
- USB activity monitoring
- Application usage monitoring
- URL access monitoring
- Rule-based insider threat detection (R1-R10)
- Risk-based alert generation
- Real-time dashboard visualization
- Email alert notification
- PDF and Excel report generation

## System Overview

Insider Watch follows a rule-based detection workflow:

User Activity Monitoring  
↓  
Rule Engine Evaluation  
↓  
Risk Assessment  
↓  
Dashboard Alert & Email Notification  
↓  
Report Generation

## Detection Rules

The system implements predefined detection rules covering:

- Abnormal session behaviour
- Excessive file activity
- USB activity monitoring
- Application policy violations
- URL access monitoring
- Context-based suspicious behaviour

## Technologies

- SMTP Email Notification
- PDF/Excel Reporting
- Windows Endpoint Monitoring
